## 🏋️‍♂️ PyFit – Personal Workout Planner

PyFit is an interactive, intelligent fitness application built with Python and Streamlit. It generates customized workout splits based on user-selected goals, experience levels, training frequency, and muscle group priorities.

***

## ✨ Features

1. Tailored Workout Splits (1–7 Days): Dynamically builds routines ranging from single-day full-body sessions to 6-day Push/Pull/Legs splits with dedicated recovery days.
2. Goal-Driven Prescriptions: Recommends targeted set, rep, and rest intervals based on your goal (Build Muscle, Increase Strength, Lose Body Fat, or Improve Endurance).
3. Adaptive Difficulty Filtering: Automatically filters exercise selection by your training experience level (Beginner, Intermediate, Advanced).
4. Priority Volume Boosting: Incorporates additional targeted exercises for muscle groups you explicitly choose to prioritize.
5. Smart Exercise Swapping: Replaces exercises on demand while preserving target muscle groups, difficulty constraints, and preventing duplicates across your routine.
6. Goal-Specific Fitness Tips: Displays actionable, grammatically mapped daily training and nutrition advice.

 ***

## 🚀 How to use

   1. Make sure Python 3.8 or higher is installed on your system
   2. Clone the repository
   3. Create a virtual environment (optional but recommended)
   4. Install streamlit 
   5. Run the app using streamlit
